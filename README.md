

# ZIBEN - AI Radar

An automated workflow built with n8n that scrapes latest AI and technology news via RSS feeds, processes and summarizes them using advanced AI models, and delivers a clean, structured report directly to Telegram.

## 🚀 Features
* Automated Data Collection: Fetches the latest updates from multiple tech and AI RSS feeds automatically.
* Smart AI Summarization: Passes raw news items through an AI model to categorize and summarize them clearly.
* Telegram Integration: Instantly delivers formatted executive reports to your Telegram chat.

## 🛠️ Tech Stack
* n8n (Workflow Automation)
* RSS Feeds (Data Source)
* AI Model / LLM (Content Processing & Categorization)
* Telegram Bot API (Alerts & Delivery)
